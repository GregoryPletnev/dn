# Bundled fonts

DN ships these fonts so that Options > Fonts/Colors works offline.
Other fonts in the list are downloaded on demand from their official
releases and checked against a pinned SHA-256 (see `src/dnfonts.pas`).

| File | Font | Author | License |
|---|---|---|---|
| `PxPlus_IBM_VGA_9x16.ttf` | PxPlus IBM VGA 9x16, The Ultimate Oldschool PC Font Pack v2.2 | VileR, https://int10h.org/oldschool-pc-fonts/ | CC BY-SA 4.0, `LICENSE-PxPlus_IBM_VGA.txt` |
| `spleen-8x16.psfu` | Spleen 2.3.0, 8x16 console font | Frederic Cambus, https://github.com/fcambus/spleen | BSD 2-Clause, `LICENSE-spleen.txt` |

The files are unmodified copies of the upstream releases.
